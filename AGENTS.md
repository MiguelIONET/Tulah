# Proyecto de trabajo

Este directorio contiene la versión independiente de neumorfismo de Tulah elegida por el usuario.

- Para las modificaciones de este proyecto, trabaja en esta carpeta.
- Conserva las seis páginas, los enlaces relativos y los recursos locales.
- No sincronices cambios con las propuestas antiguas ni con glassmorfismo salvo que el usuario lo solicite.
- La comprobación del catálogo es `node tests/catalog-browser.mjs .` desde esta carpeta.
